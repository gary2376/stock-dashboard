# 新手入門策略（範例）

這是一份給你參考的範例筆記，內容是常見、保守的交易紀律，**不是投資建議**。請改成你自己的規則：直接在「策略筆記」頁編輯或刪除，系統只會對照你筆記裡寫的內容。

## 趨勢濾網

只做上升趨勢的股票：股價必須站上50日均線，而且50日均線高於200日均線。
若股價跌破50日均線，就不要新開任何多單部位，已持有的部位也要重新檢視。
趨勢濾網沒有通過的股票，今天就不要買。

## 進場

等待整理後的突破，突破當天成交量要放大到二十日均量的一點三倍以上。
RSI 超過 70 的時候不要追價，等回檔整理後再重新評估是否進場。
突破失敗時不要加碼攤平，虧損的部位不可以再加碼。

## 風險

單筆交易的停損不可以超過百分之七，這是不可談判的規則。
報酬風險比至少要達到三比一，否則這筆交易不值得做。
每一筆交易下單之前，都要先寫下停損的價位。

| 項目 | 規則 |
| --- | --- |
| 停損 | 不超過7% |
| 報酬風險比 | 至少3比1 |
| 同時持股 | 最多八檔 |

## 市場環境

大盤在50日均線之下時，新部位的規模減半，而且只做最強的標的。
大盤跌破200日均線時，暫停所有新的進場，只管理手上已有的部位。

## 檢討

每週日花十分鐘回顧本週的每一筆交易，寫下一個教訓。
不要在財報公布前一週建立新部位，因為跳空風險太高。

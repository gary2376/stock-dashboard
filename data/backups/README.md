# 備份存放處

網頁上的「匯出備份」會把你的觀察清單、關注、持倉與投資分析打包成一個 JSON，由瀏覽器下載；這個動作是唯讀的，不會寫入這個資料夾。

要在伺服器端的這個資料夾留一份備份，請呼叫 `POST /api/backup/snapshot`（例如 `curl -X POST http://127.0.0.1:8013/api/backup/snapshot`）。「匯入備份」在覆蓋資料之前，也會自動在這裡存一份 `pre-import-*.json`。

這個資料夾本身進版控（讓 clone 下來的人也有這個資料夾），但裡面的 `*.json` 備份檔不進版控（見 `.gitignore`），因為那是你的個人資料。

要還原，請按「匯入備份」，選這個資料夾裡（或任何地方）的備份檔即可。
